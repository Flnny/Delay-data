# Representation ablation

Which **representation** of a flight, and which **head** on top of it, predicts delay
(`|ARR_DELAY| > 15`) best? Two experiments, one fixed setting:

- **Sample:** 50,000 flights drawn across 2016–2024 (stratified by year and label,
  `bakeoff/prep/build_sample.py`, seed 42).
- **Split:** temporal by day of month: train 14,690 / val 4,985 / test 30,325.
- **Seeds:** 42 / 43 / 44, mean ± std.

| Folder | What varies | How it runs |
|---|---|---|
| `bakeoff/` | the representation (SentenceTransformer, skrub, TabPFN*, skrub + HUIM), fed to one fixed MLP head; plus GBDT heads (`run_gbdt.py`) | repo scripts (`uv run`) |
| `skrub_head/` | the head on the skrub representation: MLP → **TabFM** (pretrained, in-context) | Colab notebook `skrub_head_ablation.ipynb` (GPU, no repo imports) |

\* TabPFN weights are licence-gated; that row was never evaluated.

## Results (same 50k sample, same 30,325 test rows → directly comparable)

| Representation + head | AUC | F1-macro | Accuracy |
|---|---|---|---|
| **skrub + TabFM** | **0.6336 ± 0.0001** | 0.5451 ± 0.0004 | 0.6168 ± 0.0002 |
| raw + CatBoost | 0.6009 ± 0.0016 | 0.4776 ± 0.0348 | 0.6016 ± 0.0015 |
| skrub + LightGBM | 0.5994 ± 0.0006 | 0.4933 ± 0.0230 | 0.6029 ± 0.0003 |
| skrub + MLP | 0.5982 ± 0.0014 | 0.5371 ± 0.0060 | 0.6005 ± 0.0014 |
| skrub + HUIM patterns + MLP | 0.5919 ± 0.0012 | 0.5282 ± 0.0055 | 0.5991 ± 0.0015 |
| SentenceTransformer + MLP | 0.5726 ± 0.0042 | 0.4698 ± 0.0413 | 0.5943 ± 0.0016 |

(`bakeoff/RESULTS_GBDT.md` is generated by `run_gbdt.py`; the TabFM row is from
`skrub_head/README.md`.)

Reading:
- On this sample the **head matters more than the representation**: TabFM on skrub
  beats every trained head by ~3.3 AUC points, while the trained heads (MLP, LightGBM,
  CatBoost — raw or skrub) all land at 0.598–0.601.
- Adding HUIM pattern columns to skrub costs 0.006 AUC with the MLP head.

## Not comparable with the 2020 feature ablations

The feature ablations in `../` (01b … 06) train on **2020 only** and test on **2.55M
2020 rows**; this experiment trains on 14.7k rows from nine years and tests on 30k rows.
Absolute numbers from the two must not be ranked against each other (e.g. TabFM 0.634
here vs XGBoost ≈0.68 with full 2020 data there). What carries over is the *direction*:
which head / representation wins within each setting. To settle TabFM vs GBDT on equal
terms, run both on the same split (e.g. TabFM on the 2020 ablation split, or GBDTs
trained on a comparable context size).

## Reproduce

```bash
A=exp/Tab_exp/ablations/representation/bakeoff
uv run python $A/prep/build_sample.py      # artifacts/sample.parquet (gitignored)
PYTHONPATH=. uv run python $A/run_bakeoff.py
PYTHONPATH=. uv run python $A/run_hybrid.py --winner skrub
uv run python $A/run_gbdt.py               # GBDT rows + skrub+MLP reproduction check
# TabFM head: open skrub_head/skrub_head_ablation.ipynb in Colab (see skrub_head/README.md)
```
